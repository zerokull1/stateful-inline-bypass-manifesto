## 🧭 1. Кризис Stateful Inspection

Современные WAF и IDS/IPS (L7) опираются на ведение таблиц состояний соединений (*Stateful Inspection*). Однако между анализом трафика на промежуточных шлюзах и его обработкой ядром конечного сервера (*Target*) существует архитектурный разрыв, порождаемый двумя слабостями:
1. **TCP Reassembly Desynchronization** (Асинхронность сборки пакетов из-за разности ОС шлюза и сервера).
2. **State Exhaustion Optimization** (Ресурсный компромисс коммерческих систем, заставляющий пускать пакеты вне логики ACK по ускоренному пути *Fast-Path*).

## ⚔️ 2. Побайтовая физика трехфазного обхода

Реализация метода на нижнем системном уровне требует использования сырых сокетов (*raw sockets*) и низкоуровневых перехватчиков трафика (*ingress/egress hooks*) в обход стандартного сетевого стека ОС.

```text
                  [ Инициация сессии исследователем ]
                                  │
         ┌────────────────────────┼────────────────────────┐
         ▼                        ▼                        ▼
[ ФАЗА 1: Эталон ]       [ ФАЗА 2: Модификация ]    [ ФАЗА 3: Нулевой Коллапс ]
 • TCP Fingerprint         • Сессия: Split (1 byte)   • Флаги TCP: 0x00 (Null)
   мобильного стека        • Окно (Window): 45 байт   • Нарушение логики WAF
 • Идеальный TTL=65        • Искажение TTL (TTL=90)   • RFC 793: Прием данных
 • MSS = 1350              • WAF теряет детекцию      • Сборка payload на Target
```

### Спецификация фаз

| Фаза | Уровень | Ключевые параметры | Поведение WAF / DPI | Поведение Цели (Target) |
| :--- | :--- | :--- | :--- | :--- |
| **1. Эталон** | L3/L4 | TTL=65, MSS=1350, Мобильный Fingerprint | Вносит сессию в таблицу как штатный мобильный трафик | Возвращает `SYN-ACK`. Порт открыт |
| **2. Модификация** | L3/L4 | Session Splitting (1-й байт), Window=45, TTL=90 | Фиксирует аномалию маршрута, исключает пакет из буфера сборки L7 | Принимает байт, сдвигает `Sequence Number (X+1)` |
| **3. Null-Коллапс** | L4/L7 | Payload остаток, TCP Flags = `0x00` (Null) | Видит отсутствие флага `ACK` в `ESTABLISHED`. Пускает транзитом по *Fast-Path* | Согласно **RFC 793**, принимает сегмент, склеивает payload и выполняет команду |

## 🎭 3. Концепция маскировки «Монолит»

Для предотвращения слепого блокирования легитимного конфиденциального трафика, архитектура реализует модель безупречного системного фона:

* **Сетевой уровень (L3):** Сочетание `TTL=65` и `MSS=1350` полностью эмулирует стек мобильного устройства (LTE/5G), исключая принудительную фрагментацию оператором.
* **Транспортный уровень (L4):** Разделение на два канала. Тяжелый трафик инкапсулируется в `Hysteria2 (UDP-TLS)` под видом медиа-стриминга. Точечные проверки идут через параллельные `RAW TCP` сокеты.
* **Прикладной уровень (L7) и Энтропия:** Мимикрия под доверенные SNI (Microsoft, Google, Apple) + динамический **Padding** (добавление мусорных байт), разрушающий статистические модели анализа межпакетных интервалов (**IAT**).

## 🛡️ 4. Симметричная архитектура защиты (Щит)

Пассивный анализ трафика должен быть заменен на активную inline-нормализацию.

```text
    [ Входящий аномальный поток ]
                  │
                  ▼
   ┌─────────────────────────────┐
   │    Active TCP Normalizer    │ ──> (Инжекция флага ACK, нормализация TTL)
   └─────────────────────────────┘
                  │
                  ▼
   ┌─────────────────────────────┐
   │    IAT / Entropy Engine     │ ──> (Спектральный анализ интервалов времени)
   └─────────────────────────────┘
                  │
                  ▼
      [ Валидный сетевой стек ]
```

### 4.1. Внедрение Active TCP Normalization
* **Модификация заголовков:** При обнаружении Null-пакета (`0x00`) внутри сессии `ESTABLISHED`, нормализатор принудительно инжектирует флаг `ACK` и валидный `Acknowledgment Number`.
* **Выравнивание метрик L3:** Скачки TTL внутри одной сессии принудительно перезаписываются на базовое значение сессии, уничтожая эффект десинхронизации.

### 4.2. Низкоуровневая интеграция (Netfilter / iptables / nftables)
* Очистка должна происходить в цепочке `PREROUTING` (таблица `raw`), строго до передачи пакета в подсистему `conntrack`.
* На высоких скоростях (10G+) логика реализуется на уровне **eBPF (XDP / TC)**. Программа `XDP` на лету проверяет `struct tcphdr` и модифицирует или дропает аномальные кадры, защищая Stateful-таблицы от исчерпания ресурса процессора.

### 4.3. Ликвидация слепоты SIEM-систем
Вендорам SIEM необходимо внедрить обязательные правила корреляции для событий класса `TCP Flags Anomaly: NULL Segment` с сохранением сырого дампа заголовков (PCAP) для проведения Forensics-расследований, исключая пропуск инцидентов под видом "сетевого шума".
